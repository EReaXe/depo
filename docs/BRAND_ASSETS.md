# Marka logoları

36 logo: https://github.com/filippofilip95/car-logos-dataset (Carlogos.org kaynaklı derleme). Dosya bazlı kaynak adresleri brand-sources.json içindedir. Derleme README'si MIT olarak tanımlar; marka logolarının hakları ilgili marka sahiplerine aittir. Bu uygulama markalarla resmi bağlantı iddiasında bulunmaz. Logolar yapay olarak üretilmemiştir.
